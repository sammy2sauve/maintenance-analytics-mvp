# TrueSignal — Impeccable Design Context

## Design Context

### Users
Three overlapping user types, all needing signal over noise at different depths:

- **Plant/Facility Manager** — Reviews dashboards in the morning. Makes budget and prioritization calls. Needs at-a-glance status and KPIs. Cannot afford to parse noise.
- **Maintenance Technician** — On the floor, checking what to act on next. Needs clear urgency signals and task direction. Speed and clarity are everything.
- **Reliability Engineer** — Deep-analysis user. Validates predictions, reviews trends, exports data. Needs power, depth, and trustworthy numbers.

All three need the same thing: **confidence that the signal they're seeing is real and actionable**.

### Brand Personality
**Precise. Alert. Trustworthy.**

TrueSignal is a predictive intelligence tool — not a reporting tool, not a CMMS replacement. The brand should feel like a sharp instrument: expert, calibrated, always telling you what matters.

Emotional goals: **Clarity** (no noise, no confusion — just the signal) + **Confidence** (I trust what I'm seeing).

### Aesthetic Direction
- **Dark, always.** Background slate-950 (`#0f172a`), never white or light gray.
- **Indigo + emerald duopoly.** Primary brand actions in indigo (`#6366f1`), success/safe in emerald (`#34d399`). Risk colors follow a strict semantic system: red → orange → amber → emerald.
- **Eye-catching, not flashy.** Custom SVG visualizations (gauges, EKG logo, progress rings), glassmorphism cards, glow accents — used purposefully, not decoratively.
- **Not vibecoded.** Every element should feel intentional and brand-aligned. Avoid AI-generated-feeling randomness: mismatched spacing, overused gradients everywhere, inconsistent border radii, or components that feel copy-pasted from different design systems.
- **Not a template.** Generic Tailwind UI cards with gradient headers, startup-style hero sections, or BI tool dashboard-explosion aesthetics are all wrong.
- **Not legacy CMMS.** No gray tables, no cluttered toolbars, no 2010-era software feel.

Reference: the closest analogues are Linear/Vercel (precision, dark, intentional) but with the data density of Datadog — a sharp tool that looks as capable as it is.

### Design Principles

1. **Signal over noise.** Every element must earn its place. If it doesn't communicate health, risk, or action — remove or de-emphasize it. Whitespace is not wasted space; it's signal separation.

2. **Urgency has visual weight.** CRITICAL must feel critical. The hierarchy red → orange → amber → green must be visceral, not just labeled. Size, color intensity, and placement should all reinforce risk level.

3. **Serve all three users in one view.** High-level summary at the top (manager), specific actionable items in sidebars (technician), detailed data below the fold (engineer). No page should be single-audience.

4. **Consistency builds trust.** Spacing, border radius, typography scale, and color use must be consistent across every page and component. Inconsistency signals a tool that was cobbled together — the opposite of trustworthy.

5. **Dark, intentional, non-generic.** The UI should feel custom-built for this domain — not a starter template with the color changed. Components should visually reflect the brand mission: predictive maintenance intelligence for industrial facilities.

## Tech Stack Summary
- React 19 + Vite + Tailwind CSS 3.4 (utility-only, no component library)
- Recharts for charts, Lucide React for icons
- Custom SVG components for logo, gauge, progress rings
- FastAPI backend, SQLite dev database
